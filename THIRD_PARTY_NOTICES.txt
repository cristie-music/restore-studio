Third-party notices
===================

Bass Maker includes or downloads the following third-party components.

1. BS-RoFormer 4 stems FT - separation model weights (downloaded into models\ by setup.bat)
   by SYH99999, https://huggingface.co/SYH99999/bs_roformer_4stems_ft
   Files: bs_roformer_4stems_ft.pth, config_bs_roformer_4stems_ft.yaml (= config.yaml of the model page).
   License stated on the model page: Apache-2.0 (checked 2026-10-31).
   The model separates drums / bass / other / vocals; Bass Maker uses only its bass output.

2. BS-RoFormer network code (app\roformer.py is a re-implementation for inference only)
   - lucidrains "BS-RoFormer" (MIT) https://github.com/lucidrains/BS-RoFormer
   - ZFTurbo "Music-Source-Separation-Training" (MIT) https://github.com/ZFTurbo/Music-Source-Separation-Training

3. Spotify Basic Pitch 0.4.0 - note transcription model and inference code (installed into python\)
   https://github.com/spotify/basic-pitch            License: Apache-2.0
   The ICASSP 2022 model ("nmp.onnx") ships inside the basic-pitch package.

4. Runtime downloaded by setup.bat (NOT part of the Bass Maker code)
   - CPython 3.11 (python-build-standalone builds): Python Software Foundation License
   - PyTorch: BSD-3-Clause (CUDA 12.6 build; bundles NVIDIA CUDA runtime libraries under NVIDIA's license)
   - ONNX Runtime: MIT;  librosa: ISC;  NumPy, SciPy, scikit-learn: BSD-3-Clause
   - python-soundfile: BSD-3-Clause (bundles libsndfile, LGPL-2.1);  PyYAML: MIT
   - mido: MIT;  pretty_midi: MIT;  resampy: ISC;  mir_eval: MIT;  numba / llvmlite: BSD-2-Clause
   basic-pitch declares TensorFlow as a dependency on Windows; setup.bat removes it again
   (TensorFlow: Apache-2.0) because the model runs on ONNX Runtime.

5. Code shared with Piano Maker / Guitar Splitter (notes.py, harmony.py, outputs.py): MIT, same authors.

The full list of installed Python packages with versions is in requirements.lock.txt.
